# LUMERA Marketplace

Учебный проект современного marketplace на HTML, CSS и JavaScript.

Проект включает каталог товаров, личный кабинет покупателя и панель модератора/продавца.


Возможности

Покупатель

- просмотр каталога;
- категории товаров;
- поиск товаров;
- избранное;
- корзина;
- личный кабинет;
- история заказов;
- регистрация и вход.

Модератор / продавец

- отдельная панель управления;
- добавление товаров;
- редактирование товаров;
- удаление товаров;
- изменение цены;
- изменение остатка;
- выбор категории;
- добавление описания;
- добавление изображения;
- публикация и снятие товара с публикации;
- поиск и фильтрация товаров.


Технологии

- HTML5
- CSS3
- JavaScript
- LocalStorage
