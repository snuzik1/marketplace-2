# LUMERA Marketplace

LUMERA — учебный проект современного интернет-магазина / marketplace.

Проект создаётся с нуля с целью изучения веб-разработки, интерфейсов, авторизации, управления товарами и построения полноценной архитектуры интернет-магазина.

## Возможности

### Покупатель

- просмотр каталога;
- поиск товаров;
- категории;
- избранное;
- корзина;
- регистрация и вход;
- личный кабинет;
- история заказов.

### Модератор / продавец

- отдельный кабинет;
- добавление товаров;
- редактирование товаров;
- удаление товаров;
- изменение цены;
- изменение количества товара;
- выбор категории;
- добавление описания;
- загрузка изображения;
- публикация и снятие товара с публикации;
- поиск и фильтрация товаров.

## Технологии

На текущем этапе проект использует:

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Основные ограничения
- авторизация работает на стороне клиента;
- роль пользователя хранится в LocalStorage;
- товары хранятся в LocalStorage;
- цены и остатки можно изменить через DevTools;
- данные корзины нельзя считать доверенными;
- изображения хранятся локально;
- отсутствует серверная проверка прав доступа;
- отсутствует настоящая база данных;
- отсутствует production-система авторизации.
